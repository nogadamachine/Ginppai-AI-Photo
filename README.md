# Ginppai-AI-Photo

**사진은 내 폰에서, 원본은 그대로.**

Android용 오프라인 이미지 메타데이터 클리너입니다. 사진 여러 장을 정리하고 갤러리에 새 사본으로 저장하거나 바로 공유할 수 있습니다. 계정, 광고, 구독, 서버 업로드, 처리 횟수 제한이 없습니다.

## 설치와 업데이트

1. Releases에서 `Ginppai-AI-Photo-1.2.0.apk`를 내려받습니다.
2. Android에서 APK를 열어 설치합니다. 요청되면 APK를 연 앱에만 출처 허용을 설정하고 설치 후 다시 끌 수 있습니다.
3. 기존 **이미지 클린 1.0.0** 사용자는 삭제하지 않고 덮어 설치하세요. 패키지와 서명이 같아 작업 기록과 설정을 유지합니다.

Android 10 이상이 필요합니다. Google Play 배포 앱이 아닌 직접 설치 APK입니다. 기기 보안 설정을 우회하거나 기기를 루팅할 필요가 없습니다.

## 한눈에 보는 사용법

1. **사진 추가**로 한 장 또는 여러 장을 선택합니다. 갤러리의 공유 메뉴에서 이 앱으로 보내도 됩니다.
2. 상단 설정에서 **PNG** 또는 **JPEG**를 고릅니다. 미세한 픽셀 변화는 선택 사항이며 기본값은 꺼짐입니다.
3. **N장 정리하기**를 누릅니다. 작업은 전체 목록의 대기 및 재시도 가능한 실패 항목을 대상으로 합니다.
4. 완료한 사진을 눌러 미리보거나 공유합니다. 하단 버튼 또는 더 보기 메뉴에서 완료한 사진을 한 번에 공유할 수 있습니다.

- **전체 / 대기 / 완료 / 실패** 필터로 원하는 항목만 봅니다.
- 사진 옆 메뉴에서 개별 공유와 목록 제외를 할 수 있습니다.
- 목록을 비우거나 항목을 제외해도 원본과 저장된 갤러리 사본은 지워지지 않습니다.
- 처리 중에는 현재 사진을 마친 뒤 중지할 수 있습니다.
- 알림을 허용하면 백그라운드 진행 상황을 확인하기 쉽습니다. 강제 종료 후에는 앱을 다시 열어 남은 작업을 시작하세요.
- 새 사본은 `Pictures/Ginppai-AI-Photo`에 저장됩니다. 1.0.0의 `Pictures/ImageClean` 파일은 이동하거나 삭제하지 않습니다.

## 처리 방식

| 설정 | 동작 |
| --- | --- |
| PNG 기본값 | 방향을 반영해 디코딩한 이미지를 sRGB 8비트 PNG로 저장합니다. 추가 손실 압축 없이 투명도를 유지합니다. |
| JPEG | 품질 95로 압축합니다. 투명한 부분은 흰색으로 바뀝니다. |
| 미세한 픽셀 변화 | 작은 확대, 회전, 밝기 변화를 추가합니다. 크기는 유지하지만 가장자리와 픽셀은 변합니다. |
| 픽셀 재처리 (실험) | 75% 축소 후 원래 크기로 복원하고 색차를 단순화합니다. 일부 주파수 기반 워터마크 신호를 약화하지만 색상과 디테일이 손상될 수 있습니다. 기본값은 꺼짐입니다. |

원본의 EXIF, GPS, XMP, IPTC, C2PA, 프롬프트 등의 파일 내부 기록을 새 파일에 복사하지 않습니다. 새 인코딩 결과에도 JPEG 마커 또는 PNG 청크 허용 목록을 적용하고 디코딩 검사를 수행합니다.

**메타데이터 삭제는 AI 판별 방지와 다릅니다.** Instagram을 포함한 플랫폼의 AI 표시 정책과 픽셀 분석 결과를 통제하지 않습니다. 보이지 않는 워터마크 제거, AI 표시 미부착, 검색 회피를 보장하지 않습니다.

실험 모드는 공개 `dwtDct`와 `dwtDctSvd`의 합성 이미지 12개에서만 검증했습니다. 비트 일치율 감소는 모든 검출기의 미검출이나 완전 제거를 의미하지 않습니다. **SynthID, Stable Signature, Tree-Ring과 범용 AI 판별기는 미검증**입니다. 얼굴, 글자와 미세한 질감이 중요한 사진은 실험 모드를 끄고, 켠 경우에는 저장 후 결과를 직접 확인하세요. [실험 방법과 수치](docs/WATERMARK-EXPERIMENT.md)

JPEG, PNG, WebP, HEIC, AVIF 등 기기 디코더가 읽을 수 있는 정지 이미지를 지원합니다. 동영상과 애니메이션은 지원하지 않습니다. 일부 HEIC 프로필, RAW와 손상 파일은 읽지 못할 수 있습니다.

원본 ICC는 복사하지 않고 sRGB로 변환합니다. HDR, 광색역, 고비트 심도와 완전히 투명한 픽셀의 숨은 RGB까지 보존하는 보관 도구는 아닙니다. 원본은 별도로 보관하세요.

## 개인정보와 권한

- 앱에 **인터넷 권한이 없습니다**. 사진과 사용 기록을 서버로 보내지 않습니다.
- 전체 사진 접근 권한 대신 Android 파일 선택기와 공유 권한을 사용합니다.
- 선택한 입력은 앱 내부 저장소에 임시 복사합니다. 처리 성공 또는 목록 제거 시 삭제하며, 실패하거나 대기 중이면 재시도를 위해 남습니다.
- 출력은 시스템 갤러리에 저장됩니다. Android가 관리하는 파일명과 새 저장 시각은 이미지 내부 메타데이터와 별개입니다.
- 포그라운드 서비스, 알림과 처리 중 절전 방지 권한만 사용합니다. 시스템 백업은 비활성화했습니다.

## 사용량과 기기 한계

사용 횟수와 하루 처리 장수에 인위적인 제한은 없습니다. 한 장씩 순차 처리하며 저장 공간과 메모리는 필요합니다.

- 입력 파일: 최대 256 MiB
- 한 변: 최대 32,768픽셀
- 화소 수: 최대 80,000,000픽셀
- 예상 작업 메모리: `min(384 MiB, 앱 최대 힙의 절반)` 이내
- 큰 이미지를 몰래 축소하지 않습니다. 기기가 처리할 수 없으면 실패 사유를 표시합니다.
- Android 파일 선택기와 공유 대상 앱의 제한은 그대로 적용됩니다.

## 구현과 출처

[AI Metadata Cleaner](https://aimetadatacleaner.com/)의 공개 클라이언트 동작을 분석하고 이미지 처리 사양을 Java와 Android API로 독립 구현했습니다. 해당 사이트와 관계없는 프로젝트이며 사이트 소스, 로고, 계정 또는 유료 API를 포함하지 않습니다. 서비스의 서버 제한을 우회하지 않고 기기 안에서 처리합니다.

사이트와 바이트 단위 동일성을 주장하지 않습니다. 사이트와 달리 기본값은 PNG이며 픽셀 변화는 선택 사항입니다. JPEG 압축 데이터 직접 복사 모드는 구현하지 않았습니다.

## 로컬 빌드

필요 환경: JDK 17, Android SDK Platform 35, Build Tools 35.0.0. Gradle 8.11.1과 Android Gradle Plugin 8.9.2를 사용합니다. 앱 런타임 외부 라이브러리는 없습니다.

```sh
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug assembleRelease lintRelease
```

- 디버그 APK: `app/build/outputs/apk/debug/app-debug.apk`
- 미서명 릴리스 APK: `app/build/outputs/apk/release/app-release-unsigned.apk`
- 첫 빌드는 공개 저장소에서 도구를 다운로드할 수 있습니다.
- 릴리스 서명 키와 비밀번호는 저장소에 없습니다. 직접 빌드한 디버그 APK는 공개 릴리스와 서명이 달라 덮어 설치할 수 없습니다.
- 자동 클라우드 빌드나 GitHub Actions는 사용하지 않습니다.

## 테스트

개인 사진과 실제 계정 없이 합성 이미지로 검사합니다. 테스트 앱의 작업 목록을 초기화하므로 별도의 에뮬레이터에서 실행하세요.

```sh
./gradlew connectedDebugAndroidTest
```

PNG 픽셀과 투명도, JPEG 방향과 메타데이터 제거, WebP/HEIC/AVIF 입력, 잘못된 파일, 취소와 메모리 가드, 작업 복구, 일괄 저장, UI 필터와 설정을 검사합니다.

버전별 실제 실행 결과와 미검증 범위는 [검증 기록](docs/VALIDATION.md)에 정리합니다. 릴리스 파일의 SHA-256은 Releases의 `SHA256SUMS`를 참고하세요.
