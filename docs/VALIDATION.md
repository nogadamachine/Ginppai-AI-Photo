# 1.2.0 검증 기록

2026-10-18에 로컬 Android ARM64 에뮬레이터에서 실행했습니다. 개인 사진과 실제 계정은 사용하지 않았습니다.

가로 화면에서는 설정 요약을 접어 사진 목록의 공간을 확보합니다. 저장 설정은 상단 아이콘으로 계속 열 수 있습니다. 터치 영역은 최소 48dp이며 글씨는 sp 단위입니다. 이미지 목록을 재활용하고 썸네일은 작업 스레드에서 축소 디코딩해 캐시합니다. 전용 모션을 추가하지 않고 시스템 전환을 사용합니다.

주요 본문, 상태, 설정 요약과 활성 버튼의 문자 대비를 계산했으며 검사한 조합은 모두 4.5:1 이상입니다. 키 이벤트 검사는 실제 키보드나 TalkBack 음성 사용성 검사를 대체하지 않습니다.

## 검증하지 않은 범위

- 이번 버전의 실제 휴대전화 설치, 하드웨어 성능, 장시간 절전 처리
- 각 Android 버전과 제조사별 디코더 전체 조합
- TalkBack의 실제 음성 안내와 실제 외부 키보드
- 태블릿, 폴더블의 모든 화면 크기와 자세
- Instagram 등 외부 플랫폼의 AI 표시 여부
- 보이지 않는 픽셀 워터마크의 제거 여부

에뮬레이터 API 37에서 실행했고 minSdk 29와 targetSdk 35로 빌드했습니다. 모든 Android 10 이상 기기에서 같은 코덱과 성능을 보장한다는 의미는 아닙니다. 12비트 HEIC 같은 일부 프로필은 디코더가 거절할 수 있습니다.

GitHub에는 로컬에서 서명한 APK와 체크섬을 올립니다. 서명 키, 비밀번호, 빌드 캐시, 원본 사이트 번들, 개인 경로와 실행 로그는 게시하지 않습니다. GitHub Actions는 비활성화합니다.
