# 1.6.0 검증 기록

## 범위

- Android API 37 ARM64 에뮬레이터에서 정지 이미지 저장과 변경한 UI를 검사합니다.
- 합성 입력만 사용합니다. 개인 사진, 로그인과 외부 사진 업로드를 사용하지 않습니다.
- 1.3.0 배포 APK의 서명 인증서와 새 APK의 일치를 확인하고 삭제 없는 업데이트를 검사합니다.
- 빌드, 테스트와 서명은 로컬에서 수행합니다. GitHub Actions는 비활성화 상태를 유지합니다.

홈, 저장 설정, 완료 사진과 사용 안내의 실제 화면을 확인했습니다. 라이트 테마와 다크 테마에서 변경한 화면에 내용 겹침이나 잘림이 없었고, 설정의 키보드 진입도 계측 테스트로 확인했습니다. README 스크린샷을 이번 버전의 캡처로 교체했습니다.

## 기존 버전 업데이트

별도의 새 에뮬레이터에 GitHub의 1.3.0 배포 APK를 먼저 설치했습니다. 합성 이미지로 대기 및 완료 기록을 각각 1개 만들고 JPEG 저장 형식과 이전 설정을 준비한 뒤, 1.6.0의 서명된 APK를 삭제 없이 덮어 설치했습니다.

- 두 배포 APK의 서명 인증서 SHA-256이 일치했습니다.
- 최초 설치 시각은 유지되고 버전은 1.6.0으로 변경됐습니다.
- 업데이트 전후 작업 목록 파일이 동일했고, 테스트 입력 및 완료 사본의 SHA-256도 유지됐습니다.
- JPEG 저장 형식은 유지되고 더 이상 사용하지 않는 설정 3개만 제거됐습니다.
- 업데이트 후 화면에서 대기 1개와 완료 1개를 확인했습니다.
- 이어서 대기 사진을 실제 배포 APK로 처리해 시스템 갤러리에 12 x 8 JPEG 사본을 저장했습니다.
- 업데이트와 처리 과정의 앱 충돌 로그는 없었습니다.
